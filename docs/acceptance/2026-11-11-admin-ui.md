# Admin UI browser acceptance (2026-11-11)

Build under test: `strapi-plugin-magic-messagegate` 1.0.0 from `npm pack` of branch `feat/messagegate` (commit 273fd4c), installed by extracting the tarball into an isolated host.

## Host

- Strapi 5.61.0 and `@strapi/plugin-users-permissions` 5.61.0, Node 22.23.1, SQLite.
- Loopback port 1480; fake providers (the test helper `tests/helpers/fake-providers.js`) on 1481, control on 1482.
- `NODE_OPTIONS=-r block-egress.cjs`; the browser context aborts every non-loopback request.
- Secrets generated with `crypto.randomBytes` into a mode-600 `.env`; the admin was created through `POST /admin/register-admin` by a seed script.
- Synthetic fixtures: 4 accounts (Meta, Telegram, seven.io, Twilio with a failing test), 7 templates (2 approved and 1 rejected by signed Meta webhooks, 1 draft), 32 contacts `+49 1555 0100 001…032`, 33 messages with delivered, read, failed (`META_131026`) and uncertain (socket reset) outcomes, an inbound reply and an opt-out reply.

## Accepted exceptions (native components)

- Pagination links 30 × 42 px below 768 px (`@strapi/strapi/admin` Pagination).
- BackButton 20 px high (`@strapi/strapi/admin` BackButton).
- DS Checkbox 20 × 20 px with a clickable label (template variables "Required").
- DS `Field.Action` copy icon 16 × 16 px inside the webhook URL inputs; no other target within 24 px.
- DS Tag remove buttons below 32 px at 390/320 (settings lists).
- Tables scroll horizontally inside their DS wrapper below 1024 px; all row actions are visible at 1024 and above.

## Defects found and fixed during acceptance

1. Plugin did not start: RBAC actions were registered with `category`, which Strapi only allows in the settings section (c2a56b7).
2. Phone filters found nothing: the admin fetch client sends `+` unencoded (e4fa4cf).
3. DS Badge variants below 4.5:1 (warning/danger light, primary/danger dark); replaced by token pairs (a75ae0f, 0356fde).
4. Dialogs opened from state lost focus on close (a75ae0f).
5. Template editor and routing rules squeezed on phones: DS Grid uses `col` below 520 px unless `xs` is set (8f5a654).
6. Send dialog listed one language per channel variant and asked only for one variant's variables (273fd4c).
7. Consent hints said transactional messages never need consent; the server exempts only transactional authentication templates (a75ae0f).
