## Findings

Severity: **high** = messages or receipts are lost silently, **medium** = wrong outcome for a documented case, **low** = wrong detail, **info** = documented behaviour, no change.

| #   | Area                    | Finding                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Severity | Status                                                                                                                                                                                                                                                           |
| --- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | seven.io webhooks       | seven.io sends webhooks form-encoded unless the hook's request method is `JSON` ("POST (default): application/x-www-form-urlencoded"). MessageGate only parsed JSON, so with the default setting every signed delivery report and inbound SMS was answered `200` and dropped without a trace.                                                                                                                                                                                        | high     | Fixed: the admin now says "request method JSON" next to the seven.io webhook URL (5 locales), README says it, and a signed non-JSON body logs a warning that names the fix. Parsing the form shape is not done because seven.io documents only the JSON payload. |
| 2   | REST prefix             | Webhook URLs, the Twilio `StatusCallback`, signed file links, the Meta app webhook URL and the raw-body middleware were hard-coded to `/api`. With a custom `api.rest.prefix` ([Strapi API config](https://docs.strapi.io/cms/configurations/api)) every webhook failed the signature check (no raw body) and every URL shown to the owner was wrong.                                                                                                                                | medium   | Fixed: all of them use `api.rest.prefix`.                                                                                                                                                                                                                        |
| 3   | Telegram send           | The adapter cut the HTML text to 4096 UTF-16 units. Escaped text (`&amp;` counts as one visible character) can be longer than 4096 units while within the Bot API's "1-4096 characters after entities parsing"; the cut could split an entity, which the Bot API refuses ("can't parse entities") as a permanent failure.                                                                                                                                                            | medium   | Fixed: the limit is applied to visible characters and never inside an entity; the attachment-link fallback keeps room for the link.                                                                                                                              |
| 4   | seven.io send           | MessageGate cut SMS text at 1600 characters; the official OpenAPI says `text` "may not exceed 1520 characters" and seven.io answers code 401. Texts between 1521 and 1600 characters always failed.                                                                                                                                                                                                                                                                                  | medium   | Fixed: the seven.io adapter cuts at 1520.                                                                                                                                                                                                                        |
| 5   | Text cuts               | Every `slice(0, n)` on outgoing text could cut an emoji (surrogate pair) in half and send an invalid string.                                                                                                                                                                                                                                                                                                                                                                         | low      | Fixed: `safeSlice` keeps pairs whole.                                                                                                                                                                                                                            |
| 6   | seven.io codes          | 101 with one recipient means that recipient failed, but was reported as `uncertain` (admin decision). 501 (spending limit) and 500 (no credit) did not mark the account unhealthy. 407004 (recipient unsubscribed) did not revoke consent.                                                                                                                                                                                                                                           | medium   | Fixed: 101 uses the message's own error code and is a rejection; 500/501 flag the account; 407004 revokes SMS consent.                                                                                                                                           |
| 7   | Twilio opt-out          | Error 21610 (recipient replied STOP; Twilio blocks the sender until START) failed the message but kept consent `granted`, so every later send failed again. Advanced Opt-Out's `OptOutType=STOP` was ignored when the keyword was not in MessageGate's own list (Twilio's list also has STOPALL, CANCEL, END, QUIT, …).                                                                                                                                                              | medium   | Fixed: both revoke consent for the channel (`source: provider-opt-out`). `START` is not taken as consent.                                                                                                                                                        |
| 8   | seven.io inbound        | `sms_mo` `time` is a Unix timestamp ("1605878104" in the official example); `Date.parse` returned `NaN`, so inbound SMS got the arrival time instead.                                                                                                                                                                                                                                                                                                                                | low      | Fixed.                                                                                                                                                                                                                                                           |
| 9   | seven.io HLR            | The official schema documents `roaming` as an object (`{status: unknown \| roaming \| not_roaming}`); the adapter only read a string and always returned `null`.                                                                                                                                                                                                                                                                                                                     | low      | Fixed (both shapes).                                                                                                                                                                                                                                             |
| 10  | Retry-After             | Only delay-seconds were read; the HTTP-date form (RFC 9110 10.2.3) was ignored.                                                                                                                                                                                                                                                                                                                                                                                                      | low      | Fixed, capped at 24 hours.                                                                                                                                                                                                                                       |
| 11  | Meta Graph version      | Default `v23.0` matches the official OpenAPI (v23.0) and is available until 2027-10-08 (v24.0 until 2028-02-18, v25.0 until 2028-07-29, v26.0 current).                                                                                                                                                                                                                                                                                                                              | info     | A test now fails 90 days before the end of support. Moving the default is an owner decision (see "Open decisions").                                                                                                                                              |
| 12  | Meta statuses           | Official webhook enum: `sent`, `delivered`, `read`, `failed`. `played` is not documented; the mapping keeps it as an alias of `read`.                                                                                                                                                                                                                                                                                                                                                | info     | No change.                                                                                                                                                                                                                                                       |
| 13  | Meta errors             | Throttling codes 4, 80007, 130429, 131048, 131056, 133016 are transient; 1, 2, 131000 ambiguous; 131026 marks WhatsApp unreachable; 131047 (re-engagement, 24-hour window) is a rejection. Matches the error-code page.                                                                                                                                                                                                                                                              | info     | No change.                                                                                                                                                                                                                                                       |
| 14  | 24-hour window          | Free text on WhatsApp is only routed inside 24 h after the contact's last WhatsApp message (`sender.js`, `WINDOW_MS`); outside it a template is required.                                                                                                                                                                                                                                                                                                                            | info     | No change.                                                                                                                                                                                                                                                       |
| 15  | Signatures              | Meta `X-Hub-Signature-256` (HMAC-SHA256, raw body, app secret), Twilio `X-Twilio-Signature` (HMAC-SHA1, URL + sorted form pairs), Telegram `X-Telegram-Bot-Api-Secret-Token`, seven.io `X-Signature` (HMAC-SHA256 over timestamp, nonce, method, URL, MD5 of body, optional account id; 30 s window; nonce once) all match the docs and compare in constant time.                                                                                                                    | info     | No change; covered by contract tests.                                                                                                                                                                                                                            |
| 16  | seven.io retries        | seven.io retries only on 429, 5xx and network errors, up to 14 times over 3.5 days, with fresh `X-Timestamp`/`X-Nonce` per attempt; 4xx is final. MessageGate's `401` on a bad signature and `500` on a processing error fit this.                                                                                                                                                                                                                                                   | info     | No change.                                                                                                                                                                                                                                                       |
| 17  | seven.io sandbox        | `POST /api/sms` has no sandbox or debug switch in the current docs or OpenAPI (only a `debug` field in the response). Every accepted SMS is billed.                                                                                                                                                                                                                                                                                                                                  | info     | The live suite only sends with an explicit opt-in.                                                                                                                                                                                                               |
| 18  | Twilio test credentials | Test credentials work for `POST /Messages` and Lookup v2 with the magic numbers (`From +15005550006` valid, `+15005550001` → 21212, `+15005550007` → 21606, `+15005550008` → 21611; `To +15005550001` → 21211, `+15005550002` → 21612, `+15005550003` → 21408, `+15005550004` → 21610, `+15005550009` → 21614). They answer 403 for every other resource (so the account check `GET /Accounts/{sid}` cannot run), do not accept a Messaging Service and trigger no status callbacks. | info     | The live suite uses them for the error mapping.                                                                                                                                                                                                                  |
| 18a | Twilio 21611            | "SMS queue for this number is full" was a permanent rejection; nothing was sent and a later try works.                                                                                                                                                                                                                                                                                                                                                                               | low      | Fixed: transient (next account or retry with backoff).                                                                                                                                                                                                           |
| 19  | Idempotency             | None of the four APIs offers an idempotency key for sends. MessageGate never retries an ambiguous send; seven.io's own 180-second duplicate block (402) is reported as `uncertain` because the first copy was sent.                                                                                                                                                                                                                                                                  | info     | No change.                                                                                                                                                                                                                                                       |
| 20  | Unicode / GSM-7         | `smsSegments` follows GSM 03.38 (basic set, extension table counts double) and UCS-2 (70/67, astral characters count two units).                                                                                                                                                                                                                                                                                                                                                     | info     | No change.                                                                                                                                                                                                                                                       |

## Follow-ups

- 2026-11-24 ([#18](https://github.com/Schero94/Magic-MessageGate/issues/18)): the send answer's `messages[].message_status` (`accepted`, `held_for_quality_assessment`, `paused`; official OpenAPI `MessageStatus`) was not read, so a message Meta held for [template pacing](https://developers.facebook.com/documentation/business-messaging/whatsapp/templates/template-pacing) was reported as sent. Fixed: status `held` until Meta's status webhook decides (`failed` 132015 when Meta drops it).
