# Contract tests against the providers' official specs

`npm test` runs `tests/contract-meta.test.js`, `tests/contract-twilio.test.js`, `tests/contract-seven.test.js` and `tests/contract-telegram.test.js`. They need no network and no credentials: every adapter request is captured in memory and checked against the provider's own specification, and the specs' own examples are fed back through the adapters and webhook handlers.

## What is pinned

`tests/contract/specs/` holds the parts of the official specifications that MessageGate uses (the operations it calls and every component they reference). `npm run contract:specs` rebuilds them; `npm run contract:specs -- --check` exits with 1 when an upstream source changed. Both need network and are run by a maintainer, not by CI.

`tests/contract/validator.js` is a small JSON Schema validator without dependencies. It reads `allOf` the way OpenAPI generators do (members merged before validation); strict JSON Schema would reject every Meta message, see below.

## What each suite proves

| Provider | Requests                                                                                                                                                                                                                                                                                                 | Responses                                                                                                                                                         | Webhooks                                                                                                                                              |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| Meta     | every body MessageGate builds (template, text, image, document, video, reply buttons) and templates rendered by the template engine (text/document headers, named and positional parameters, URL, quick reply and copy-code buttons) are valid `Message`s; template submit body; documented query fields | the spec's send examples, phone number info, error examples (`META_<code>`), template list examples, media download flow                                          | spec-valid payloads (text, button reply, status) pass the signature check and are stored; a changed byte gives 401; every documented status is mapped |
| Twilio   | SMS (number or Messaging Service), RCS text with media, RCS Content template: only documented form fields, typed per spec; Lookup `Fields` value; Content API rich card                                                                                                                                  | 201 example → Message SID; account example; Lookup examples → line type; Content create example                                                                   | every parameter the handler reads is on Twilio's lists; the signature matches Twilio's own test vector from twilio-node                               |
| seven.io | SMS form fields, the documented 1520-character limit, `foreign_id` pattern; HLR query; webhook registration (`GET`/`POST`/`DELETE /hooks`, form fields `target_url`, `event_type`, `request_method=JSON`, `id`)                                                                                          | SmsResponse, balance, HLR (with the `roaming` object); hooks list (both the reference page's and the OpenAPI's shape), create and delete answers, bare auth codes | the official `dlr` and `sms_mo` examples, signed as the signing page describes, are processed; a forged signature gives 401                           |
| Telegram | `sendMessage` (plain and with inline keyboard), `sendPhoto`, `sendDocument`, `getFile`, `answerCallbackQuery`, `setWebhook`: only documented parameters; the secret token follows the documented rules                                                                                                   | `Message`, `File`, `ResponseParameters` (429 `retry_after`)                                                                                                       | `Update`s with `/start` linking, text, photo, location and `callback_query` are processed; a wrong secret gives 401                                   |

Contract tests prove that MessageGate speaks the documented protocol. They do not prove that a provider behaves as documented; that is what the [live tests](./live-tests.md) are for.

## Known defects in the official specs

The tests ignore these errors (and only these). Each one contradicts the provider's own reference pages.

| Spec     | Defect                                                                                                                                                                                                                                                                                                                                                                  | Evidence                                                                                                                                         |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Meta     | `TemplateComponent.index` has the pattern `^[2-6, 11-14]$` (a character class), while its description says "Position index of the button (0-9)" and its example is `"0"`.                                                                                                                                                                                               | spec text                                                                                                                                        |
| Meta     | `TemplateComponent.sub_type` lists `quick_reply`, `url`, `catalog`, but copy-code buttons are sent with `sub_type: "copy_code"`.                                                                                                                                                                                                                                        | [copy code button templates](https://developers.facebook.com/docs/whatsapp/business-management-api/message-templates/copy-code-button-templates) |
| Meta     | Incoming webhook messages (`IncomingMessage` → `TextMessage`, `InteractiveMessageReply`, …) extend the outgoing `BaseMessageProperties` (required `messaging_product`, `recipient_type`, `to`; no `from`, `id`, `timestamp`), so no real webhook message validates. The tests validate the envelope and each message's type part (`text`, `interactive`, …) separately. | [webhook messages reference](https://developers.facebook.com/documentation/business-messaging/whatsapp/webhooks/reference/messages)              |
| Meta     | The spec requires `template.language.policy`. MessageGate now sends `"deterministic"` (its only value) to match.                                                                                                                                                                                                                                                        | spec text                                                                                                                                        |
| Twilio   | `twilio/card` has `additionalProperties: false` without `body`, which Twilio documents for RCS (up to 1600 characters).                                                                                                                                                                                                                                                 | [twilio/card](https://www.twilio.com/docs/content/twiliocard)                                                                                    |
| Twilio   | Lookup v2 response fields are declared without `nullable`, but the spec's own examples (and the API, for every data package not requested) return `null`.                                                                                                                                                                                                               | spec examples                                                                                                                                    |
| seven.io | `GET /hooks` answers `{ data: [{ hooks: {…}, success }] }` in the OpenAPI, but `{ success, code, hooks: [{…}] }` on the reference page (also what the live suite recorded as `before.hooks`). The adapter reads both shapes; the contract test feeds both through it.                                                                                                   | [webhooks endpoint](https://docs.seven.io/en/rest-api/endpoints/webhooks)                                                                        |
| seven.io | The official `sms_mo` example's sender `49176123456789` has one digit too many for a German mobile number; the test uses a valid synthetic number.                                                                                                                                                                                                                      | libphonenumber                                                                                                                                   |
